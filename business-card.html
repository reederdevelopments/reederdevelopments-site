1. Inline Live Customization

Click directly on any text element (name, title, phone number, email, or capability tags) to edit it. When in vCard Save mode, the vector QR code updates live as you type so scanning the card adds your contact directly to iOS/Android Contacts.

2. Commercial Print Shop Ready

Sending to a commercial printer (Vistaprint, Printulu, Wizardz)? Keep layout on Front & Back Studio, toggle Bleed: ON (91×61mm), and click Print / Save PDF with Margins set to None and Background graphics enabled.

3. In-House A4 10-Up Cut Sheets

Printing on thick A4 cardstock? Switch Layout to A4 Cut Sheet (10-Up) to generate Page 1 (10× Fronts) and Page 2 (10× Backs) aligned in a centered 2×5 grid with precision trim lines for double-sided duplex printing.
